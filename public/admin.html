🧹 Позачергова ручна чистка флуду

Примусовий запуск щотижневого алгоритму перевірки прямо зараз.

Ця дія виконує повний цикл щотижневої чистки не чекаючи неділі:

  • Перевіряє тижневі повідомлення кожного учасника відповідно до норми.
  • Учасники зі схваленим рестом зберігають імунітет.
  • Учасники без норми отримують +1 попередження (варн).
  • Учасники, які досягли ліміту варнів, кікаються з Telegram-чату ботом.
  • Лічильники тижневих повідомлень скидаються на 0 для нового тижня.
  • Надсилається звітний протокол у флуд-чат.
