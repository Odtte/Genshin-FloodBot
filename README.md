# 🌌 Genshin Flood Bot & Web Dashboard

> Повноцінний Telegram-бот для контролю флуду (Genshin Impact фандом) з базою даних у Google Sheets (працює як онлайн Excel), веб-дашбордом для кожного учасника та адмін-панеллю. Створений для безкоштовного хостингу на **Vercel**.

---

## 📋 Огляд концепції та можливостей

1. **📊 База даних у Google Sheets**:
   - Працює як інтерактивна таблиця Excel прямо в браузері.
   - Аркуші створюються автоматично:
     - `Users` (UID, Telegram ID, @username, ім'я, тижневі та загальні повідомлення, варни, статус, дати рестів).
     - `Settings` (прив'язаний чат, норма повідомлень, мова, час чистки).
     - `RestRequests` (історія та активні заявки на рест із кількістю повідомлень на момент подачі).

2. **🧹 Автоматичні тижневі чистки (Щонеділі)**:
   - Працює за розкладом через **Vercel Cron Jobs** (щонеділі о 20:00 за Києвом / GMT+3).
   - Якщо в учасника активний рест — він отримує **🛡️ Імунітет**.
   - Якщо повідомлень менше за тижневу норму (наприклад, < 50):
     - Нараховується попередження (варн).
     - При перевищенні ліміту варнів (3/3) учасник автоматично кікається з флуду.
   - Лічильники повідомлень обнуляються на новий тиждень, а бот публікує гарний звіт у групу.

3. **🏖️ Система рестів (відпусток від флуду)**:
   - Команда: `/rest <кількість><d/w/m> <причина>` (наприклад: `/rest 5d екзамени`, `/rest 2w відпустка`, `/rest 1m практика`).
   - Заявка відправляється адміністраторам з інлайн-кнопками: **[✅ Схвалити]** та **[❌ Відхилити]**.
   - Адміністратори бачать, скільки повідомлень набрав користувач за цей тиждень — якщо у нього півтора повідомлення, а завтра чистка, адміни можуть відхилити підозрілу заявку!

4. **🔒 Прив'язка лише до однієї групи**:
   - Бот ексклюзивно обслуговує одну групу, де виконано команду `/setup`. Інші чати ігноруються.

5. **🌐 3 мови на вибір (UA, ENG, RU)**:
   - Українська (за замовчуванням), Англійська, Російська.
   - Власник флуду може змінити мову командою `/setlang <ua|eng|ru>` або через адмін-дашборд.

6. **💻 HTML, CSS, JS Дашборд**:
   - Стильний темний дизайн у Genshin Impact Glassmorphism стилі (палітра Анемо, Електро, Піро).
   - **Персональна картка учасника**: фірмова картка мандрівника з UID, прогрес-баром норми, варнами, статусом ресту.
   - **Таблиця лідерів (Leaderboard)**: рейтинг за поточний тиждень та за весь час.
   - **Живий зворотний відлік**: показує точний час до недільної чистки.
   - **Адмін-панель (`/admin`)**: схвалення рестів з вебу, зміна лімітів і налаштувань, ручний запуск чистки.

## 🚀 Покрокове налаштування та розгортання

### Крок 1. Створення Telegram Бота

1. Відкрийте [@BotFather](https://t.me/BotFather) у Telegram і створіть нового бота командою `/newbot`.
2. Скопіюйте отриманий **API Token** (наприклад: `7123456789:AAH...`).
3. ⚠️ **ВАЖЛИВО**: У налаштуваннях бота вимкніть режим приватності (Group Privacy), щоб бот бачив звичайні повідомлення у групі для їх підрахунку:
   - Надішліть `/mybots` -> оберіть вашого бота -> **Bot Settings** -> **Group Privacy** -> натисніть **Turn off**.

---

### Крок 2. Налаштування Google Sheets (Бази Даних)

1. Створіть нову порожню Google Таблицю на [Google Sheets](https://sheets.new).
2. Скопіюйте її **Spreadsheet ID** з адресної панелі браузера:
   `https://docs.google.com/spreadsheets/d/`**`1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms`**`/edit`
3. Створіть Google Cloud Сервісний акаунт:
   - Перейдіть у [Google Cloud Console](https://console.cloud.google.com/).
   - Створіть новий проект (наприклад, `Genshin-Flood-Bot`).
   - Перейдіть у **APIs & Services** -> **Library** -> знайдіть та увімкніть **Google Sheets API**.
   - Перейдіть у **IAM & Admin** -> **Service Accounts** -> натисніть **Create Service Account**.
   - Введіть назву (наприклад, `flood-bot-service`) і натисніть **Create and Continue** -> **Done**.
   - Відкрийте створений сервісний акаунт -> перейдіть на вкладку **Keys** -> **Add Key** -> **Create new key** -> формат **JSON** -> завантажте файл ключа.
4. Скопіюйте email сервісного акаунта (виглядає як `flood-bot-service@project.iam.gserviceaccount.com`).
5. Відкрийте вашу Google Таблицю -> натисніть **Поділитися (Share)** -> додайте email сервісного акаунта з правами **Редактор (Editor)**.

---

### Крок 3. Розгортання на Vercel

1. Завантажте цей репозиторій на свій **GitHub**.
2. Перейдіть на [Vercel](https://vercel.com/) і натисніть **Add New...** -> **Project**.
3. Імпортуйте репозиторій з GitHub.
4. У розділі **Environment Variables** додайте такі змінні:

| Змінна | Приклад значення | Опис |
| :--- | :--- | :--- |
| `BOT_TOKEN` | `7123456789:AAH...` | Токен від @BotFather |
| `APP_URL` | `https://your-bot.vercel.app` | URL вашого проекту на Vercel |
| `GOOGLE_SHEETS_ID` | `1BxiMVs0XRA5...` | ID вашої Google Таблиці |
| `GOOGLE_SERVICE_ACCOUNT_EMAIL` | `service@project.iam...` | Email із завантаженого JSON |
| `GOOGLE_PRIVATE_KEY` | `"-----BEGIN PRIVATE KEY-----\n..."` | Приватний ключ з JSON (з лапками) |
| `ADMIN_SECRET` | `mypassword123` | Пароль для входу у веб-адмінку |
| `CRON_SECRET` | `cron_secret_abc` | Секретний токен для Vercel Cron |

5. Натисніть **Deploy**.

---

### Крок 4. Активація Webhook для Telegram

Після завершення деплою на Vercel відкрийте у браузері посилання:
```
https://your-bot.vercel.app/api/webhook?setup=true
```
Ви отримаєте відповідь:
```json
{ "status": "ok", "message": "Webhook successfully set to https://your-bot.vercel.app/api/webhook" }
```
Тепер бот активовано і він слухає запити в режимі Serverless 24/7!

---

### Крок 5. Підключення до групи Telegram

1. Додайте бота до вашої групи флуду з правами **Адміністратора** (щоб він міг видавати варни та кікати неактивних).
2. Надішліть у групу команду:
   ```
   /setup
   ```
3. Бот прив'яжеться до вашої групи і надішле вітальне повідомлення з налаштуваннями та посиланням на дашборд!

## 📜 Список команд бота

### Для всіх учасників:
- `/whoiam` (або `/whoami`) — **паспорт мандрівника**: генерує красиву картинку з Genshin-дизайном та текстом зі статистикою повідомлень за **день / тиждень / місяць / весь час**, прогресом норми, варнами та статусом. Можна також перевірити іншого учасника: `/whoiam @username` або відповівши на його повідомлення.
- `/stats` або `/profile` — текстова картка активності та посилання на веб-профіль.
- `/rest <час><d/w/m> <причина>` — подати запит на рест.
  - Приклади: `/rest 5d сесія`, `/rest 2w відпустка`, `/rest 1m лікарняний`.
- `/top` — топ найактивніших учасників тижня.
- `/dashboard` — отримати персональне посилання на веб-дашборд.
- `/help` — довідка з усіх команд.

### Для адміністраторів та власника:
- `/setup` — прив'язати бота до поточної групи (тільки 1 група).
- `/clean` — провести позачергову ручну чистку.
- `/setmin <число>` — змінити щотижневу норму (наприклад: `/setmin 100`).
- `/setlang <ua|eng|ru>` — перемкнути мову чату.
- `/warn [причина]` (у відповідь на повідомлення) — видати варн учаснику.
- `/unwarn` (у відповідь на повідомлення) — зняти варн.
- `/kick` (у відповідь на повідомлення) — виключити учасника з чату.

## 🖥️ Локальний запуск та тестування

Якщо ви бажаєте протестувати дашборд та бота локально перед деплоєм:

1. Створіть файл `.env` на основі `.env.example`:
   ```bash
   cp .env.example .env
   ```
2. Вкажіть ваші ключі та токени у `.env`.
3. Запустіть сервер:
   ```bash
   npm start
   ```
4. Відкрийте у браузері:
   - Головний дашборд: `http://localhost:3000`
   - Адмін-панель: `http://localhost:3000/admin`
   - Бот автоматично запуститься в режимі Polling!
